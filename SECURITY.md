# Security

GoEF has no supported published runtime version at this stage. Use GitHub's private vulnerability reporting if the repository offers it. Otherwise ask the maintainer for a private contact channel without posting vulnerability details or credentials in a public issue.

Provide the affected revision, impact, and the smallest synthetic reproduction over the private channel. Remove connection strings, personal information, production schemas, and row data. The [security and lifecycle contract](docs/architecture/SECURITY_AND_LIFECYCLE.md) describes the controls the implementation will need to prove.
