# Measure a comparable data workload

Status: Proposed. The example is a planned acceptance case and has no runnable GoEF API yet.

Capture allocations, elapsed time and SQL round trips for a fixed ordered result with a controlled fixture. Planned comparisons cover GoLINQ against native loops and database queries against native drivers, with separate server time and client materialization. Record versions and a reproducible command.

Feature IDs: LINQ-CONFORMANCE-001, QUERY-PARAM-001.
