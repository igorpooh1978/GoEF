# Handle portable errors

Status: Proposed. The example is a planned acceptance case and has no runnable GoEF API yet.

Match the stable kind with errors.Is and read approved structured fields through errors.As. The planned example distinguishes uniqueness, cancellation, stale versions and unknown commit outcome without logging row values or credentials. Unknown native failures remain unclassified for retry.

Feature IDs: ERR-CONTRACT-001, ERR-CONSTRAINT-001, ERR-CANCEL-001.
