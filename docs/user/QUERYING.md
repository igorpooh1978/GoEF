# Filter and project a database query

Status: Proposed. The example is a planned acceptance case and has no runnable GoEF API yet.

Build a typed predicate from registered fields and captured values. The planned example observes parameter binding and applies an explicit order before pagination. An unsupported predicate fails during translation before any provider command.

Feature IDs: QUERY-PARAM-001, QUERY-UNSUPPORTED-001, LINQ-QUERYABLE-001.
