2. **The master plan and probe report disagree on handshake history.** Section 16.1 still describes all candidates as untested for live handshakes. The report and source register record narrow, standalone handshakes for Context7 and Microsoft Learn, with project client configuration pending. Clarify the plan's wording so a reader can distinguish standalone protocol evidence from enabled project client use and optional database inspection. [Master plan](../../roadmap/MASTER_PLAN.md) · [Probe report](MCP_REPORT.md)
3. **The format check depends on Git checkout settings.** In this clean Windows worktree, `gofmt -l .` listed seven tracked Go files. `git ls-files --eol -- .` showed LF in the committed blobs and CRLF in the worktree under system `core.autocrlf=true`. After normalizing the worktree bytes to LF they matched the blobs, and formatting each blob through stdin was byte-identical. Specify LF checkout in the documented reproduction steps or enforce LF for Go fixtures in a separately scoped change. [Fixture report](GO_FEASIBILITY.md)
