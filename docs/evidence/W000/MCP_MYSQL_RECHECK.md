## Independent source controls and provider effect

Oracle's [exact release note](https://dev.mysql.com/doc/relnotes/mysql/8.4/en/news-8-4-13-1.html) identifies 8.4.13.1, dated 2026-11-24, as a Critical Security Patch Update. Oracle's [8.4 Reference Manual §15.3.3](https://dev.mysql.com/doc/refman/8.4/en/implicit-commit.html) lists the two sampled DDL statements and documents the implicit commit before execution. Both pages were read directly through the browser research surface. They provide the release and capability controls.

The existing GitHub connector supplied a separate source identity check. `mcp__codex_apps__github_fetch_file` on `mysql/mysql-server` with `path="MYSQL_VERSION"` and `ref="14f6f5119f993f74a8514352108d9337182d5be5"` returned blob `9783cca95af92742c600dc42cb6be9e1876e2fe0`. Its major, minor, patch and update fields were 8, 4, 13 and 1, and its maturity was LTS. The public GitHub ref lookup independently resolved `mysql-8.4.13.1` to the same commit. This verifies tagged build metadata through a repository read. The connector did not return the Oracle release-note page.
