# Migration operations

Status: Proposed. This reference describes the intended contract. Its usage examples are planned.

Proposed commands describe create, alter, drop, explicit rename, keys, checks, indexes, seed data and provider extensions. Give each operation a deterministic representation, reversibility, data-loss level and provider transaction requirement. Snapshots and history must be verified before applying effects.

Feature IDs: MIG-API-001, MIG-RENAME-001, MIG-DRIFT-001.
